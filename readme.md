## Using this repo (READ)

**!! WARNING !!**

The folder `Drivers/` generated by CubeMX is not tracked by git. \
This is to save space since this directory only contains automatically generated files and some binaries.

When cloning this repository, or to apply any change to the .ioc file, remember to use CubeMX to generate the code.

If you add any .c file in User/Src, remember to add its path in the `target_sources` function of `CMakeLists.txt`.



## Project Organisation

### File Tree Overview

- `Core/` : CubeMX generated files.
- `User/` : All manually written .c and .h files


## Compiling

Requirements :
- **CMake**
- **ninja** (build system)

- **arm-none-eabi toolchain** (ARM cross compilers)
	- can be installed manually on linux
	- ??? on windows


Use the Debug or Release configurations already generated by CubeMX.


## Flashing

The executable to be flashed, after compilation, is found at `build/\<configuration>/\<project_name>.elf`.

If OpenOCD is used to flash, there are executable scripts in the root of the project such as `flash_debug.sh`.
